# 設計資料

このプロジェクトの要件定義書・詳細設計書は、このツール自身で読み込める CSV（UTF-8 BOM 付き）で管理しています。

| ファイル | 内容 |
|---|---|
| `要件定義書.csv` | 要件（目的・前提・用語・機能・非機能・対象外） |
| `詳細設計書.csv` | 設計。「上位要件」列で要件定義書の要件 ID を参照する |

Excel で開いて編集できます（保存するときは「CSV UTF-8」形式を選んでください）。

## ID の付け方

- 要件: `G-`（目的）、`C-`（前提）、`T-`（用語）、`F-`（機能）、`N-`（非機能）、`X-`（対象外）
- 設計: `TEC-`（技術構成）、`STA-`（起動）、`DST-`（配布）、`STR-`（構成）、`DAT-`（データモデル）、`PRC-`（処理）、`API-`、`UI-`（画面）、`ERR-`（エラー処理）、`SEC-`（セキュリティ）、`TST-`（テスト）

一度付けた ID は変えないでください（変えるとリンクが切れます）。削除した ID は再利用しないでください。

## このツールで読み込む方法

1. 文書「要件定義書」「詳細設計書」を作り、トレース関係「要件定義書 → 詳細設計書」を登録する。
2. カラム定義を次のように設定して取り込む（ヘッダ行は 1 行目）。
3. 関連表「要件-設計対応表」を作り、`詳細設計書.csv` をもう一度取り込む（設計の「上位要件」列から、要件 → 設計のつながりを作る）。

**要件定義書**

| 列 | 型 | 設定 |
|---|---|---|
| 要件ID | ID | |
| 分類 | enum | 選択肢: 目的 / 前提 / 用語 / 機能 / 非機能 / 対象外 |
| 大項目 | 文字列 | |
| 要件 | 文字列 | 表示列にする |
| 補足 | 文字列 | |

**詳細設計書**

| 列 | 型 | 設定 |
|---|---|---|
| 設計ID | ID | |
| 分類 | enum | 選択肢: 技術構成 / 起動 / 配布 / 構成 / データモデル / 処理 / API / 画面 / エラー処理 / セキュリティ / テスト |
| 対象 | 文字列 | 表示列にする |
| 設計内容 | 文字列 | |
| 実装箇所 | 文字列 | リスト形式、区切り文字 `;` |
| 上位要件 | 文字列 | リスト形式、区切り文字 `;` |

**要件-設計対応表**（関連表。`詳細設計書.csv` を取り込む）

| 列 | 型 | 設定 |
|---|---|---|
| No | ID | ID を自動で振る（接頭辞 `RD-`） |
| 上位要件 | 文字列 | リスト形式、区切り文字 `;`、関連表のキー: 上位側、参照先: 要件定義書 |
| 設計ID | 文字列 | 関連表のキー: 下位側、参照先: 詳細設計書 |

## 整合性の確認

`tests/test_docs.py` が、2 つの CSV をこのツールで取り込み、次を確認します。設計書を更新したらテストを実行してください。

- 取り込み時のエラー・警告が 0 件（enum の選択肢外の分類が無いことなど）
- 設計から参照されていない要件が無い
- 上位要件の無い設計が無い
- 存在しない要件 ID を参照している設計が無い（リンク切れが無い）
