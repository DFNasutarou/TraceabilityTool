# トレーサビリティツール 操作マニュアル

表形式の仕様書・設計書（CSV / TSV / Excel）を取り込み、文書どうしの項目のつながり（トレース）を確認するツールです。

- すべての処理はこの PC の中だけで行います。インターネットや外部のサーバには一切通信しません。
- 画面はブラウザで表示しますが、接続先はこの PC 自身（`127.0.0.1`）だけです。他の PC からは接続できません。
- 取り込んだ元のファイルは保存しません（ツール用に変換したデータだけを保存します）。

---

## 1. 起動と終了

このフォルダは、どこにコピーしても使えます。インストールや Python は不要です。

### Windows

1. `TraceabilityTool.exe` をダブルクリックします。
2. 黒いウィンドウ（コンソール）が開き、少しするとブラウザでツールの画面が開きます。
3. 終了するときは、黒いウィンドウで `Ctrl + C` を押すか、ウィンドウを閉じます。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選んでください。

### Ubuntu

1. 端末でこのフォルダに移動し、次を実行します。

   ```
   ./TraceabilityTool
   ```

2. ブラウザでツールの画面が開きます（開かない場合は、表示された URL をブラウザで開いてください）。
3. 終了するときは、端末で `Ctrl + C` を押します。

「許可がありません」と表示された場合は、一度だけ `chmod +x TraceabilityTool` を実行してください（Windows を経由してコピーすると、実行の許可が外れることがあります）。

### 起動時のオプション

| オプション | 説明 |
|---|---|
| `--data-dir フォルダ` | データの保存先を変更する |
| `--port 番号` | ポート番号を変更する（既定は 8765。他のソフトと重なって起動できない場合に使う） |
| `--no-browser` | ブラウザを自動で開かない |

例（Windows）: `TraceabilityTool.exe --port 8800`

## 2. データの保存場所とバックアップ

取り込んだデータは、次のフォルダに保存されます。

- Windows: `C:\Users\<ユーザー名>\TraceabilityTool\data`
- Ubuntu: `~/TraceabilityTool/data`

このフォルダには機密情報が含まれます。取り扱いに注意してください。

- **バックアップ**: ツールを終了してから、`data` フォルダごとコピーしてください。
- **ツールの更新**: ツールのフォルダを新しいものに差し替えても、データはそのまま使えます（データはツールのフォルダとは別の場所にあるため）。
- `data\logs` には動作の記録が残りますが、項目の値（仕様の内容）は書き込みません。

## 3. 基本の流れ

1. **文書を登録する** … 仕様書・設計書の種類ごとに「文書」を作ります。
2. **表を取り込む** … ファイルを選び、列の型を設定して取り込みます。取り込むたびに新しい「版」になります。
3. **トレース関係を登録する** … 「要件定義書 → 画面定義書」のように、上位と下位の文書を結びます。
4. **リンクを確認・追加する** … 参照 ID 列から自動でリンクができます。足りないリンクは画面から追加します。
5. **トレース状況を確認・出力する** … 網羅率や、リンクの無い項目を確認し、Excel / CSV に出力します。

---

## 4. 文書の登録とカラム定義

文書一覧の「＋ 文書を追加」から、文書名を入力して作成します。

カラム定義（列の構成）は、ここで決めても、取り込み時にファイルの見出しから作っても構いません。

### 列の型

| 型 | 内容 |
|---|---|
| ID | 項目を一意に識別する列。文書に必ず 1 つ必要です。空欄や重複があると取り込めません |
| 番号 | 整数。全角数字や桁区切りの `,` も読み取ります |
| 文字列 | 任意の文字 |
| enum | 決められた選択肢のどれか。選択肢を 1 行に 1 つ入力します |
| bool | はい／いいえ。「真とみなす文字列」「偽とみなす文字列」を設定します（初期値: `○` `Yes` `TRUE` `1` など／`×` `No` `FALSE` `0` など）。英字の大文字・小文字、全角・半角は区別しません |

### リスト形式

1 つのセルに複数の値が区切り文字で書かれている列は、「リスト形式」にチェックを付け、区切り文字を指定します。

- セル内で改行して値を並べている場合は、「改行」にチェックを付けます。タブで区切っている場合は「タブ」にチェックを付けます。
- それ以外の区切り文字は入力欄に書きます。複数ある場合はスペースで区切って入力します（例: `; ,`）。
- 空白そのものを区切り文字にする場合は、入力欄に `\s` と書きます。
- 「改行」と入力欄の区切り文字は同時に使えます（例: 改行にチェックを付け、入力欄に `;` → 改行と `;` のどちらでも区切る）。

### 参照 ID 列（リンクの自動作成）

上位の文書の ID が書かれている列（例: 画面定義書の「上位要件」列）は、型を「文字列」にして「参照先」に上位の文書を選びます。
取り込むと、その値からリンクが自動で作られます。

- 参照 ID 列を使うには、2 つの文書の間にトレース関係が必要です。関係が無い状態で参照先を選ぶと、その列に警告と「関係を登録（〇〇 を上位にする）」ボタンが表示されるので、押して登録してください（参照先が下位の文書の場合は「下位にする」を押します）。文書一覧の下部「トレース関係」からも登録できます。
- 1 つのセルに複数の ID がある場合は、リスト形式にしてください。

### 使われている値から enum を作る

文字列の列に表示される「使われている値から enum を作る」を押すと、その列で実際に使われている値を選択肢にして、型を enum に変えます（押すと値の一覧が表示されるので、確認して OK を押します）。

- 取り込み画面では、取り込もうとしているファイルの値を使います。
- 文書の設定画面では、取り込み済みの最新版の値を使います。変更は「保存」を押すと、次回の取り込みから適用されます。
- 値の種類が 300 を超える列は enum にできません。

### 表示列

ID だけでは中身が分からないため、ID と一緒に表示する列を 1 つ選べます（リンクの一覧や出力で使います）。指定しない場合は ID の次の列を使います。

## 5. 取り込み

文書一覧で、文書の「取り込み」を押します。

1. **ファイル選択** … 次のどちらかで読み込みます。
   - 「ファイルを選ぶ」: CSV / TSV / Excel（.xlsx）を選びます。旧形式の .xls は .xlsx で保存し直してください。
   - 「テキストを貼り付ける」: CSV / TSV のテキストを貼り付けます。Excel で表の範囲（見出しの行を含む）をコピーして、そのまま貼り付けることもできます。形式は、1 行目にタブがあれば TSV、無ければ CSV と自動で判定します（手動でも選べます）。
2. **読み込み設定**
   - 文字コード（CSV・TSV のみ）: 通常は自動判定で構いません。文字化けする場合は Shift_JIS / UTF-8 を選びます。
   - ヘッダ行: 見出しの行が何行目かを指定します。プレビューの行をクリックしても指定できます。
   - シート（Excel のみ）: 複数選ぶと、行を順につなげて 1 つの表として取り込みます（見出しは同じである必要があります）。
   - 結合セルは、結合された範囲のすべての行に同じ値が入っているものとして扱います。
3. **列の対応付けと検証**
   - 各列について「ファイルのどの列から値を取るか」と型を確認します。どの列にも対応付けられていないファイルの列は、「＋」で列として追加できます。
   - 「検証する」を押すと、エラーと警告が表示されます。
     - **エラー**（取り込めません）: ID の空欄・重複、ID 列の未設定など
     - **警告**（取り込めます）: 整数でない番号、選択肢に無い値、参照先に無い ID など。警告になった値はそのまま保存され、一覧で色付きで表示されます
   - 版のラベル（例: 「第3版」）を入力して「取り込む」を押します。

ここで設定した列の構成は、次回以降の取り込みに引き継がれます。

## 6. 項目一覧と詳細

文書名をクリックすると項目一覧が開きます。

- 全文検索、列ごとの絞り込み、見出しクリックでの並べ替えができます。
- 「版」で過去の版を選ぶと、その時点の内容を見られます（読み取り専用）。
- 「上位」「下位」はリンクの数、「状態」はトレースの状態です（`-` はその方向の関係が無いことを表します）。
- 行をクリックすると、右側に詳細とリンクの一覧が表示されます。
  - リンク先の ID をクリックすると、相手の文書のその項目へ移動します。
  - 検索欄に ID や表示列の文字を入れて「検索」→「追加」で、リンクを手動で追加できます。
  - 「削除」で手動リンクを消せます。自動で作られたリンクは「無効化」になり、次に取り込んでも無効のままです。「元に戻す」で戻せます。
  - 「確認済み」で要確認の状態を解除します。

---

## 7. トレース状況

上部の「トレース状況」で、関係（上位 → 下位）ごとの状況を確認できます。

| 表示 | 意味 |
|---|---|
| 網羅率 | リンクを持つ項目の割合 |
| 下位なし | 上位文書の項目で、下位文書へのリンクが 1 本も無いもの（設計・実装の漏れの可能性） |
| 上位なし | 下位文書の項目で、上位文書へのリンクが 1 本も無いもの（根拠の無い項目の可能性） |
| リンク切れ | リンク先の ID が最新版に存在しないもの（ID の誤記や、項目の削除） |
| 要確認 | リンクを確認した後に、どちらかの項目の内容（備考を含むすべての列）が変わったもの。内容を確認して「確認済み」にしてください |

トレースの評価は、各文書の**最新版**を対象にします。

### 出力

- **トレースマトリクス**: 上位 ID と下位 ID の対応表（リンクの無い項目も含む）
- **未トレース一覧**: 網羅率の集計と、下位なし・上位なし・リンク切れ・要確認の一覧（文書一覧の「未トレース一覧（全関係）」ですべての関係をまとめて出力できます）

Excel（.xlsx）と CSV を選べます。CSV では、Excel で開いたときに数式として実行されるのを防ぐため、`=` `+` `-` `@` で始まる値の先頭に `'` を付けて出力します。

---

## 8. 版と差分

文書の「版・差分」で、取り込んだ版の一覧を確認できます。

- 比較元と比較先の版を選んで「比較」を押すと、追加・削除・変更された項目が表示されます。変更された項目は、変わった列の変更前と変更後を表示します。列の追加・削除・名前の変更も表示されます。
- 差分は Excel / CSV に出力できます。
- 不要な版は削除できます（元に戻せません）。最新版を削除すると、1 つ前の版が最新版になります。

---

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| ブラウザが開かない | コンソール（端末）に表示された `http://127.0.0.1:8765/` をブラウザで開いてください |
| 起動してすぐ終了する | 他のソフトがポート 8765 を使っている可能性があります。`--port 8800` などを付けて起動してください |
| 文字化けする | 取り込みの「文字コード」で Shift_JIS / UTF-8 を切り替えてください |
| 「サーバに接続できません」と表示される | ツールが終了しています。もう一度起動してください |
| 「許可されていないホスト名でのアクセスです」と表示される | `http://127.0.0.1:8765/` または `http://localhost:8765/` で開いてください |
