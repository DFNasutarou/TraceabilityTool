# トレーサビリティツール 操作マニュアル

表形式の仕様書・設計書（CSV / TSV / Excel）を取り込み、文書どうしの項目のつながり（トレース）を確認するツールです。

- すべての処理はこの PC の中だけで行います。インターネットや外部のサーバには一切通信しません。
- 画面はブラウザで表示しますが、接続先はこの PC 自身（`127.0.0.1`）だけです。他の PC からは接続できません。
- 取り込んだ元のファイルは保存しません（ツール用に変換したデータだけを保存します）。

---

## 1. 起動と終了

このフォルダは、どこにコピーしても使えます。インストールや Python は不要です。

### Windows

1. `TraceabilityTool.exe` をダブルクリックします。
2. 黒いウィンドウ（コンソール）が開き、少しするとブラウザでツールの画面が開きます。
3. 終了するときは、黒いウィンドウで `Ctrl + C` を押すか、ウィンドウを閉じます。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選んでください。

### Ubuntu

1. 端末でこのフォルダに移動し、次を実行します。

   ```
   ./TraceabilityTool
   ```

2. ブラウザでツールの画面が開きます（開かない場合は、表示された URL をブラウザで開いてください）。
3. 終了するときは、端末で `Ctrl + C` を押します。

「許可がありません」と表示された場合は、一度だけ `chmod +x TraceabilityTool` を実行してください（Windows を経由してコピーすると、実行の許可が外れることがあります）。

### 起動時のオプション

| オプション | 説明 |
|---|---|
| `--data-dir フォルダ` | データの保存先を変更する |
| `--port 番号` | ポート番号を変更する（既定は 8765。他のソフトと重なって起動できない場合に使う） |
| `--no-browser` | ブラウザを自動で開かない |

例（Windows）: `TraceabilityTool.exe --port 8800`

## 2. データの保存場所とバックアップ

取り込んだデータは、次のフォルダに保存されます。

- Windows: `C:\Users\<ユーザー名>\TraceabilityTool\data`
- Ubuntu: `~/TraceabilityTool/data`

起動時に `--data-dir` を指定した場合は、そのフォルダに保存されます。

画面右上の「保存先フォルダを開く」、または文書一覧の下部の「フォルダを開く」で、このフォルダをエクスプローラー（Ubuntu ではファイルマネージャー）で開けます。文書一覧の下部には保存先のパスも表示されます。

このフォルダには機密情報が含まれます。取り扱いに注意してください。

- **バックアップ**: ツールを終了してから、`data` フォルダごとコピーしてください。
- **ツールの更新**: ツールのフォルダを新しいものに差し替えても、データはそのまま使えます（データはツールのフォルダとは別の場所にあるため）。
- `data\logs` には動作の記録が残りますが、項目の値（仕様の内容）は書き込みません。

## 3. 基本の流れ

1. **文書を登録する** … 仕様書・設計書の種類ごとに「文書」を作ります。
2. **表を取り込む** … ファイルを選び、列の型を設定して取り込みます。取り込むたびに新しい「版」になります。
3. **トレース関係を登録する** … 「要件定義書 → 画面定義書」のように、上位と下位の文書を結びます。
4. **リンクを確認・追加する** … 参照 ID 列から自動でリンクができます。足りないリンクは画面から追加します。
5. **トレース状況を確認・出力する** … 網羅率や、リンクの無い項目を確認し、Excel / CSV に出力します。
6. **新しい版を取り込んだら** … 文書の「版・差分」で変わった内容を確認し、「トレース状況」の「要確認」タブで、影響を受けるリンクを確認して「確認済み」にします（7 章「要確認をまとめて確認済みにする」）。

## 4. 文書の登録とカラム定義

文書一覧の「＋ 文書を追加」から、文書名を入力して「作成して取り込みへ」を押します。文書が作られ、続けて取り込み画面が開きます。あとで取り込む場合は、取り込み画面の「中止」で文書一覧に戻れます。

カラム定義（列の構成）は、ここで決めても、取り込み時にファイルの見出しから作っても構いません。

列が多い場合は「＋ 列をまとめて追加」を押し、列名を区切り文字で区切ったテキストを貼り付けて「追加する」を押すと、まとめて列を作れます。Excel の見出しの行をコピーして貼り付けることもできます（区切り文字はタブ・カンマ・改行から自動で判定します。手動でも選べます）。追加した列は文字列型になるので、必要に応じて型を変えてください。

列の並び順は、各行の左端の「⋮⋮」をつまんで上下にドラッグするか、「↑」「↓」で変えられます。

### 列の型

| 型 | 内容 |
|---|---|
| ID | 項目を一意に識別する列。文書に必ず 1 つ必要です。空欄や重複があると取り込めません。ファイルに ID の列が無い場合は、自動で振れます（下の「ID を自動で振る」） |
| 番号 | 整数。全角数字や桁区切りの `,` も読み取ります |
| 文字列 | 任意の文字 |
| enum | 決められた選択肢のどれか。選択肢は 1 つずつ欄に入っていて、「⋮⋮」のドラッグで並べ替え、「×」で削除できます。下の欄に入力して「追加」で増やせます（複数行を貼り付けると 1 行ずつ追加されます） |
| bool | はい／いいえ。「真とみなす文字列」「偽とみなす文字列」を設定します（初期値: `○` `Yes` `TRUE` `1` など／`×` `No` `FALSE` `0` など）。英字の大文字・小文字、全角・半角は区別しません |

### リスト形式

1 つのセルに複数の値が区切り文字で書かれている列は、「リスト形式」にチェックを付け、区切り文字を指定します。区切り文字の欄には初期値として `;` が入っているので、ファイルに合わせて変えてください。

- セル内で改行して値を並べている場合は、「改行」にチェックを付けます。タブで区切っている場合は「タブ」にチェックを付けます。
- それ以外の区切り文字は入力欄に書きます。複数ある場合はスペースで区切って入力します（例: `; ,`）。
- 空白そのものを区切り文字にする場合は、入力欄に `\s` と書きます。
- 「改行」と入力欄の区切り文字は同時に使えます（例: 改行にチェックを付け、入力欄に `;` → 改行と `;` のどちらでも区切る）。

### ID を自動で振る

ファイルに ID の列が無い場合は、ID 型の列で「ID を自動で振る」にチェックを付け、接頭辞（例: `REQ-`）、桁数、開始番号を指定します。取り込むと、データの行の順に `REQ-001`、`REQ-002` … のような ID が振られます。

- 取り込み画面でファイルに ID の列が無いときは、「＋ 列を追加」で列を足し、型を「ID」にしてから設定してください（元の ID 列だった列は自動で文字列型に戻ります）。
- **注意**: 取り込むたびに、行の順に番号を振り直します。行を挿入・削除した表を取り込み直すと、同じ行でも ID が変わり、リンクがずれます。行の追加は、表の末尾に足すか、取り込んだ後に項目一覧の編集モード（6 章）で行ってください。

### 参照 ID 列（リンクの自動作成）

上位の文書の ID が書かれている列（例: 画面定義書の「上位要件」列）を「参照 ID 列」にすると、取り込んだときにその値からリンクが自動で作られます。取り込み画面（または文書の設定画面）で、その列を次の手順で設定します。

1. 型を「文字列」にする。
2. 1 つのセルに複数の ID が書かれている場合は「リスト形式」にチェックを付け、区切り文字を確認する（初期値は `;`。ファイルがカンマ区切りなら `,` に変える）。
3. 「参照先」で上位の文書を選ぶ。
4. 2 つの文書の間にトレース関係が無いと、その列に警告と「関係を登録（〇〇 を上位にする）」ボタンが表示されるので、押して登録する（参照先が下位の文書の場合は「下位にする」を押す）。

- トレース関係は、文書一覧の下部「トレース関係」でも登録できます（登録のフォームは、文書が 2 つ以上あるときに表示されます）。
- 文書を新しく作る画面ではまだ文書が無いため、手順 4 のボタンの代わりに「作成した後に登録してください」と表示されます。取り込み画面で登録してください。

### 使われている値から enum を作る

文字列の列に表示される「使われている値から enum を作る」を押すと、その列で実際に使われている値を選択肢にして、すぐに型を enum に変えます（確認のダイアログは出ず、結果が画面右下に表示されます）。

- セルの中で改行している値は、改行を含んだまま 1 つの選択肢になります。1 つのセルに複数の値を改行で区切って書いている場合は、先に「リスト形式」の「改行」にチェックを付けてから押してください（ボタンを押したときにも案内が表示されます）。
- 選択肢の欄に、値がファイルに出てきた順で入ります。内容を確認し、必要なら順番を並べ替えたり、値を直したりしてください（例: 高・中・低の順にする）。
- ファイルの値が変わったときは、「使われている値で選択肢を作り直す」で選択肢を入れ直せます。
- 元の文字列に戻す場合は、型を「文字列」に変えます。

- 取り込み画面では、取り込もうとしているファイルの値を使います。
- 文書の設定画面では、取り込み済みの最新版の値を使います。変更は「保存」を押すと、次回の取り込みから適用されます。
- 値の種類が 300 を超える列は enum にできません。

### 重要度（横並び表示での見せ方）

各列に、横並び表示での重要度を「低」「中」「高」から選べます（初期値は「低」）。

- 低: 小さめの文字で表示します（分類や実装箇所など、参考程度に見る列向け）。
- 中: 普通の大きさで表示します。
- 高: 大きめの太字で表示します（要件の本文や項目名など、いちばん読みたい列向け）。

重要度で変わるのは文字の大きさだけです。カードの中の列の順番は、カラム定義の並び順のとおりです。

重要度は表示だけに使う設定なので、文書の設定画面で変えて「保存」すると、取り込み直さなくてもすぐに横並び表示に反映されます。

### レイアウト（幅・列名の後の改行）

各列に、表示の幅を「自動」「小」「中」「大」「全幅」から選べます（初期値は「自動」）。

- 項目一覧: その幅の列になります（自動は内容に合わせ、長い値は省略します）。
- 横並び表示のカード: カラム定義の並び順のとおりに、1 行に「小」なら 4 個、「中」なら 3 個、「大」なら 2 個並ぶ幅で表示します（優先度・分類・○× などの短い列を「小」にすると、カードがコンパクトになります）。「自動」「全幅」は 1 行を使います。入りきらない列は次の行に回ります。

「列名の後で改行」にチェックを付けると、横並び表示のカードで列名の下に値を表示します。外すと列名を左に、値を右に表示し、長い列名は途中で「…」と省略します（マウスを乗せると全体が見えます）。

列の一覧の上の「レイアウトのプレビュー」で、横並び表示のカードの見た目を確かめながら設定できます（文書の設定画面では最新版の 1 つ目の項目、取り込み画面では検証した 1 つ目の行の値で表示します）。

レイアウトも表示だけの設定なので、文書の設定画面で変えて「保存」すると、取り込み直さなくても反映されます。

### 表示列

ID だけでは中身が分からないため、ID と一緒に表示する列を 1 つ選べます（リンクの一覧や出力で使います）。指定しない場合は ID の次の列を使います。

ID の次の列が「分類」のような列だと、リンクの一覧で項目の中身が分かりません。取り込み画面（または文書の設定画面）の列一覧の下にある「表示列」で、項目名などの列を選んでおくことをお勧めします。

## 5. 取り込み

文書一覧で、文書の「取り込み」を押します。

1. **ファイル選択** … 次のどちらかで読み込みます。
   - 「ファイルを選ぶ」: CSV / TSV / Excel（.xlsx）を選びます。旧形式の .xls は .xlsx で保存し直してください。
   - 「テキストを貼り付ける」: CSV / TSV のテキストを貼り付けます。Excel で表の範囲（見出しの行を含む）をコピーして、そのまま貼り付けることもできます。形式は、1 行目にタブがあれば TSV、無ければ CSV と自動で判定します（手動でも選べます）。
2. **読み込み設定**
   - 文字コード（CSV・TSV のみ）: 通常は自動判定で構いません。文字化けする場合は Shift_JIS / UTF-8 を選びます。
   - ヘッダ行: 見出しの行が何行目かを指定します。ファイルの先頭のほうで、値の入ったセルが最も多い行を見出しとして自動で推定します（先頭にタイトル行や空行がある帳票でも、多くの場合は正しく推定されます）。プレビューで色の付いた行が見出しになっているか確認し、違う場合は見出しの行をクリックして指定してください。
   - データの範囲: 見出しとデータの間に説明の行がある場合は「データの開始行」を、表の下に注記などがある場合は「データの終わり」を指定します。
     - データの終わりは「最後の行まで」「指定した行まで」「最初の空行の手前まで」から選びます。表と注記の間が空行で区切られていれば「最初の空行の手前まで」が便利です（シートごとに判定します）。
     - プレビューの上の「プレビューの行を押して指定」で「データの開始行」「データの終了行」を選んでから行を押しても指定できます。取り込まない行は灰色で表示されます。
     - プレビューには先頭 30 行と末尾 20 行が行番号付きで表示されます（間の行は「… n 行を省略 …」と表示されます）。
   - シート（Excel のみ）: 複数選ぶと、行を順につなげて 1 つの表として取り込みます（見出しは同じである必要があります）。シートにチェックを付けると、そのシートのプレビューに切り替わります。シートが複数あるときは、プレビューの上のタブで見るシートを切り替えられます。
   - 結合セルは、結合された範囲のすべての行に同じ値が入っているものとして扱います。
3. **列の対応付けと検証**
   - 各列について「ファイルのどの列から値を取るか」と型を確認します。どの列にも対応付けられていないファイルの列は、「＋」で列として追加できます。
   - 「ファイルの列」の選択肢は、まだどの列にも対応付けていない列が上に、他の列で使っている列が下（「〇〇で使用中」）にまとまっています。
   - このステップに進むと自動で検証され、エラーと警告の件数が表示されます。列の設定を変えると「定義を変更しました。もう一度検証してください」と表示されるので、「検証する」を押して検証し直してください。
     - **エラー**（取り込めません）: ID の空欄・重複、ID 列の未設定など
     - **警告**（取り込めます）: 整数でない番号、選択肢に無い値、参照先に無い ID など。警告になった値はそのまま保存され、一覧で色付きで表示されます
     - 「行」はファイル上の行番号です（Excel の行番号と同じで、見出しより上の行も数えます）。
   - 版のラベル（例: 「第3版」）を入力して「取り込む」を押します。ラベルは省略できます（省略すると版番号 v1, v2 … だけで表示されます）。

ここで設定した列の構成は、次回以降の取り込みに引き継がれます。

## 6. 項目一覧と詳細

文書名をクリックすると項目一覧が開きます。

- 全文検索、列ごとの絞り込み、見出しクリックでの並べ替えができます。1 ページに 500 件まで表示します。
- enum・bool の列の絞り込みは、欄を押して表示される選択肢の一覧から選びます（複数選べます。「選択肢に無い値」「空欄」も選べます）。
- 「折り返して全文を表示」にチェックを付けると、長い値を折り返してすべて表示します。外すと 1 行に収まる分だけ表示します（この設定はブラウザに記憶されます）。
- リスト形式の列で値が 2 つ以上ある場合は、1 つ目だけを表示し、値の後ろの「‹ 1/3 ›」で 2 つ目以降に切り替えられます。
- 「版」で過去の版を選ぶと、その時点の内容を見られます（読み取り専用）。
- 「上位」「下位」はリンクの数、「状態」はトレースの状態です（`-` はその方向の関係が無いことを表します）。
- 行をクリックすると、右側に詳細とリンクの一覧が表示されます（画面の幅がおよそ 900px 以下のときは一覧の下に表示され、自動でそこまでスクロールします）。
  - リンク先の ID をクリックすると、相手の文書のその項目へ移動します。
  - 検索欄に ID や表示列の文字を入れて「検索」→「追加」で、リンクを手動で追加できます。
  - 「削除」で手動リンクを消せます。自動で作られたリンクは「無効化」になり、次に取り込んでも無効のままです。「元に戻す」で戻せます。確認のダイアログは出ず、結果は画面右下に表示されます。
  - 「確認済み」で要確認の状態を解除します。
  - 「上位・下位と横並びで見る」を押すと、横並び表示（次の節）が開きます。

### 横並び表示

「上位の項目 ｜ この文書の項目 ｜ 下位の項目」の 3 列に、それぞれの項目のすべての列を並べて表示します。

- 中央の列には、今見ている文書の項目がすべて、文書の順番どおりに縦に並びます。スクロールして見て、項目を押すと、左右の列がその項目の上位・下位に切り替わります（選んでいる項目は青い枠で示します）。項目が多い文書では、選んだ項目の前後 100 件ずつを表示し、「前の項目を表示」「次の項目を表示」で広げられます。
- 上位・下位の項目が複数ある場合は縦に並びます。列ごとにスクロールして見られます。
- 画面の幅が狭いときも 3 列のまま表示し、収まらない分は横にスクロールして見ます。
- 上位・下位の項目の ID を押すと、その項目の文書に切り替えて表示し直します（上位・下位を順にたどれます）。
- 「前の項目」「次の項目」（キーボードでは Alt + ← / →）でも、同じ文書の項目を順に選べます。
- 各カードの中は、カラム定義の並び順のとおりに、列のレイアウト（4 章「レイアウト」）に従って並びます。文字の大きさは列の重要度（4 章「重要度」）で変わります。
- 「折り返して全文を表示」を外すと、各値を 1 行に収まる分だけ表示します。
- リスト形式の値は「‹ ›」で切り替えます。「列名の後で改行」の列では列名の隣に、それ以外の列では値の後ろにあります。
- 無効化したリンクは表示しません。リンク切れの項目は赤く表示します。

### 編集モード

最新版を表示しているときに「編集」を押すと、項目を画面で直せます。

- セルを押すと、その場で編集できます（Esc で閉じます）。変更したセルは黄色、追加した行は緑で表示されます。
  - 文字列・番号は入力欄に入力します。リスト形式の列は 1 行に 1 つ入力します。
  - enum・bool は選択肢から選びます（リスト形式の enum はチェックボックスで複数選びます）。enum は「＋ 選択肢を追加」で選択肢を足せます。
- 「＋ 行を追加」で項目を追加します。ID を入力してください（ID を自動で振る文書では、次の番号が入っています）。
- 行の「削除」で項目を削除します（取り消し線で表示され、「戻す」で戻せます）。
- 「＋ 列を追加」で列を足せます。足した列は、次回の取り込みでは「ファイルに無い列」になります（文書の設定画面で、ファイルの列に対応付けられます）。
- ID のセルも編集できます。取り込み済みの項目の ID を変えると、保存したときに、その項目のリンク（手動・自動とも）と、他の文書がその項目を参照している ID（参照 ID 列の値）をすべて新しい ID に付け直します。
  - ID を変えただけなら「要確認」にはなりません。参照している文書の版は増えず、最新版の値だけが書き換わります。
  - 保存の画面に、付け直すリンクの数と、参照している文書の項目が表示されます。
  - 編集前に別の項目で使われていた ID には変えられません（2 つの項目の ID の入れ替えや、削除した項目の ID の再利用）。いったん別の ID にして保存してから、もう一度変えてください。
  - **元のファイルの ID も直してください。** 直さずに取り込み直すと古い ID に戻り、リンクが切れます。
- 「保存…」を押し、保存のしかたを選んで「保存する」を押します。
  - **新しい版として保存**: 編集前の版はそのまま残ります。「版・差分」で編集前と比べられます。
  - **今の版を書き換えて保存**: 版の数は増えません。編集前の内容は残りません。
- 内容を変えた項目へのリンクは、相手側で「要確認」になります（取り込みで内容が変わった場合と同じです）。
- 「編集をやめる」を押すと、変更を破棄します（変更がある場合は確認が表示されます）。

## 7. トレース状況

上部の「トレース状況」で、関係（上位 → 下位）ごとの状況を確認できます。

| 表示 | 意味 |
|---|---|
| 網羅率 | リンクを持つ項目の割合 |
| 下位なし | 上位文書の項目で、下位文書へのリンクが 1 本も無いもの（設計・実装の漏れの可能性） |
| 上位なし | 下位文書の項目で、上位文書へのリンクが 1 本も無いもの（根拠の無い項目の可能性） |
| リンク切れ | リンク先の ID が最新版に存在しないもの（ID の誤記や、項目の削除） |
| 要確認 | リンクが作られた後（または最後に「確認済み」にした後）に、どちらかの項目の内容（備考を含むすべての列）が変わったもの。新しい版を取り込むと、内容が変わった項目のリンクが要確認になります。内容を確認して「確認済み」にしてください |

トレースの評価は、各文書の**最新版**を対象にします。

### 要確認をまとめて確認済みにする

「要確認」タブで、確認したリンクの左のチェックを付け（見出しのチェックで全件を選べます）、「選択した N 件を確認済みにする」を押すと、まとめて確認済みにできます。1 件ずつ処理する場合は、項目詳細の「確認済み」を使います。

### 出力

- **トレースマトリクス**: 上位 ID と下位 ID の対応表（リンクの無い項目も含む）
- **未トレース一覧**: 網羅率の集計と、下位なし・上位なし・リンク切れ・要確認の一覧（文書一覧の「未トレース一覧（全関係）」ですべての関係をまとめて出力できます）

どちらも Excel（.xlsx）と CSV を選べます。ファイル名には関係名が入ります（例: `トレースマトリクス_要件定義書→画面定義書.xlsx`、`未トレース一覧_要件定義書→画面定義書.csv`、全関係の場合は `未トレース一覧_全関係.xlsx`）。ボタンを押すと画面右下に「ダウンロードしました: ファイル名」と表示され、ファイルはブラウザのダウンロード先（通常は「ダウンロード」フォルダ）に保存されます。CSV では、Excel で開いたときに数式として実行されるのを防ぐため、`=` `+` `-` `@` で始まる値の先頭に `'` を付けて出力します。

## 8. 版と差分

文書の「版・差分」で、取り込んだ版の一覧を確認できます。

- 開くと、最新版と 1 つ前の版の差分が自動で表示されます。別の版どうしを比べるときは、比較元と比較先の版を選んで「比較」を押します。差分には、追加・削除・変更された項目が表示されます。変更された項目は、変わった列の変更前と変更後を表示し、実際に変わった文字を濃い色で示します（変更前は赤、変更後は緑）。列の追加・削除・名前の変更も表示されます。
- 差分は Excel / CSV に出力できます。
- 不要な版は削除できます（元に戻せません）。最新版を削除すると、1 つ前の版が最新版になります。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| ブラウザが開かない | コンソール（端末）に表示された `http://127.0.0.1:8765/` をブラウザで開いてください |
| 起動してすぐ終了する | 他のソフトがポート 8765 を使っている可能性があります。`--port 8800` などを付けて起動してください |
| 文字化けする | 取り込みの「文字コード」で Shift_JIS / UTF-8 を切り替えてください |
| 「サーバに接続できません」と表示される | ツールが終了しています。もう一度起動してください |
| 「許可されていないホスト名でのアクセスです」と表示される | `http://127.0.0.1:8765/` または `http://localhost:8765/` で開いてください |
